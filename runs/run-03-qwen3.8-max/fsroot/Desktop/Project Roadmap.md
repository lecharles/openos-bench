# OpenOS Roadmap

## v1.0 (shipped)
- [x] Desktop shell: menu bar, wallpaper, desktop icons
- [x] Window manager: drag / 8-way resize / traffic lights / z-order
- [x] Dock with magnification + launch bounce + genie minimize
- [x] Spotlight (Cmd+Space, fuzzy search)
- [x] Finder (icon + list views, breadcrumbs, sidebar)
- [x] 14 apps
- [x] Server-side persistence
